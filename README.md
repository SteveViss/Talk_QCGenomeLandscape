# Intégration ADNe-occurrences — présentation

Diapositives Quarto/revealjs présentant les résultats de la recherche sur la complémentarité
des séquences ADN (NCBI, BOLD) et des données d'occurrence (Atlas) pour le suivi de la
biodiversité au Québec. Manuscrit visé : *FACET*.

Auteurs : Vissault, Fuster, Gravel, Brochu, Langlois.

## Modifier la présentation

1. Éditer [index.qmd](index.qmd)
2. Prévisualiser localement :

```bash
quarto preview index.qmd
```

## Publier sur GitHub Pages

```bash
quarto publish gh-pages
```

Génère la présentation, crée/met à jour la branche `gh-pages` et la pousse vers GitHub.

## Plan de la présentation

- Introduction : biais dans les données de biodiversité, potentiel et limites de l'intégration ADNe
- Matériel et méthodes
- Résultats
  - Résumé des requêtes (Atlas, NCBI/BOLD)
  - O1 — Complémentarité taxonomique, spatiale, temporelle des sources
  - O2 — Qualité des données de référence
  - O3 — Qualité des assignations
- Discussion : synergies entre sources, contrôle qualité, dark diversity, méthodes émergentes

Ceci est un squelette : les figures, tableaux et sections marqués `à compléter` / `à insérer`
seront remplis au fur et à mesure que les résultats sont finalisés.
