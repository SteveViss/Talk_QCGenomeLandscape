# Limites identifiés

La qualité des analyses de métabarcoding dépend:

1. Échantillonage (présence de contaminants, période, dispositif ex. Présence de réplicats technique et de blanc)
2. Laboratoire
3. Analyse bioinformatique (qualité des bases de données de références)
   1. Certaines séquences peuvent être assigné à des espèces du japon. Il y a pas de régionalisation des bases de données
   2. L'absence d'un taxon dans la base de données de référence amène une non-assignation et parfois même une assignation à une espece génétiquement proche.

Support ces affirmations par la littérature.
1. Valider que le type de pipeline utilisée n'influence pas les résultats
2. Montrer que la qualité des bases de données de références influence les résultats
